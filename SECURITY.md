# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 1.0.0   | :white_check_mark: |
| < 1.0.0 | :x:                |

## Reporting a Vulnerability

If you discover a security vulnerability within RepoPilot, please send an e-mail to security@repopilot.com. All security vulnerabilities will be promptly addressed. We take security very seriously.
